# Brand direction

365Canopy brings clarity beneath a broad green canopy. The tree connects the brand to a permissions hierarchy: resources branch outward, group membership explains the leaves, and coverage shows where the view ends.

Use the generated transparent symbol (`assets/canopy-logo-pillowy.png`) beside the wordmark **365Canopy**, set in Segoe UI Semibold. This fresh direction uses overlapping rounded foliage cushions, a softly curved trunk and visible supporting branches. The supplied tree reference informed the general pillowy character; this is an original composition. Earlier detailed, minimal and tripod concepts are preserved in `assets/`. Keep the symbol independent of the wordmark for the desktop icon. All versions are concept assets; assess legibility at 16/24/32 pixels and create a production vector before a stable release. The alpha includes a multi-resolution ICO with 16 through 256 pixel variants.

Palette: forest #166534, emerald #15803D, leaf #86EFAC. Light surfaces #F5F8F5 / #FFFFFF, ink #172B20. Dark surfaces #101A14 / #18251C, ink #E9F3EC. Amber is reserved for incomplete evidence. Green indicates emphasis and collected state; it does not certify tenant safety.

Use generous space around the mark, flat surfaces, modest corner radii and quiet separators. Avoid decorative tree textures behind evidence. The mockup is an interactive design concept with invented tenant data, not a screenshot or implemented collector.
