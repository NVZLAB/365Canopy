.NET 10 / Windows Desktop runtime
The app is published self-contained. The build copies the exact runtime-pack license
files and available third-party notices into licenses/Microsoft.NETCore.App and
licenses/Microsoft.WindowsDesktop.App in the application package. Runtime versions
are recorded in 365Canopy.runtimeconfig.json; dependency versions are in its deps.json.

Inno Setup 6 is build tooling. Its generated installer/uninstaller is covered by
Inno Setup's license; see https://jrsoftware.org/files/is/license.txt .
No Inno compiler installation is included in the Canopy source or app package.

The older command-line authentication spike downloads Microsoft modules separately
through Setup-Checkpoint.ps1; those modules are not bundled in the desktop package.
